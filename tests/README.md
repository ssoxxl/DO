# 검증

프로젝트 루트에서 `node tests/scenario-paths.cjs` 실행.

네 챕터의 선택지, 시간 초과, 미니게임 성공·실패를 탐색하고 스탯 한계 적용 후에도 모든 장면과 15개 엔딩에 도달 가능한지 검사한다. 존재하지 않는 목적지와 다른 챕터로 잘못 연결된 장면도 검사한다.

`node tests/build-site.cjs`: Cloudflare Pages 배포 파일 포함/제외, 참조 파일 존재, OG 절대 URL 생성을 검사한다.

브라우저 확인: 390px 화면에서 챕터 선택 직후 대사와 선택지 3개가 자동 표시됨. 이동·조사·수첩 조작 요소 0개. 선택으로 다음 장면에 진입하고 멘탈 92와 상태창 표시가 일치함. 미니게임은 명시적인 계속 버튼으로 진입. 모바일 가로 넘침 없음.

`pixel-mobile.png`에서 현재의 상태창·인물 장면·대사·선택지 화면을 캡처하고 시각 검수했다. `pixel-start.png`는 시작 화면 참고 이미지다.

광고 실제 게재와 공유 서비스의 링크 미리보기는 배포 환경에서 별도 확인해야 한다.
