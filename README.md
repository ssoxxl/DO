## 🚀 워드프레스 하위도메인(서브도메인) + CNAME 무료 배포 가이드

본 프로젝트는 **정적 웹(HTML/CSS/JS)** 구조이므로, Cloudflare Pages나 Vercel에 무료로 배포하고 기존 워드프레스 도메인에 CNAME으로 연결하면 **트래픽 비용 0원 & 애드센스 즉시 승계**가 가능합니다.

---

### 방법 1: Cloudflare Pages로 3분 만에 배포하기 (가장 추천!)

1. **Cloudflare 계정 생성 및 로그인** (무료)
2. **Workers & Pages** 메뉴 이동 → **Create application** → **Pages** 탭 선택
3. **Upload assets** (직접 업로드) 선택
   - 프로젝트 이름 입력: 예) `cult-survival`
   - 현재 폴더(`C:\ssoxxl\9. App\도를아십니까`)의 파일 전체(`index.html`, `css/`, `js/`, `assets/`)를 드래그 앤 드롭
   - **Deploy site** 클릭 (즉시 `https://cult-survival.pages.dev` 주소로 배포 완료!)
4. **워드프레스 도메인 CNAME 연결하기**:
   - Cloudflare Pages 프로젝트 설정 → **Custom domains** 탭 클릭
   - **Set up a custom domain** 클릭
   - 사용할 서브도메인 입력 (예: `cult.yourdomain.com` 또는 `game.yourdomain.com`)
   - DNS 제공자(가비아, 후이즈, 클라우드플레어 등)에 접속하여 CNAME 레코드 추가:
     - **유형**: `CNAME`
     - **이름(호스트)**: `cult`
     - **값(대상)**: `cult-survival.pages.dev`
   - 5~10분 후 `https://cult.yourdomain.com`으로 SSL(https)까지 자동 적용되어 접속됩니다.

---

### 방법 2: Vercel로 배포하기

1. [Vercel](https://vercel.com) 로그인
2. 현재 폴더를 GitHub 레포지토리에 올리거나, Vercel CLI (`npx vercel`)로 즉시 배포
3. 프로젝트 대시보드 → **Settings** → **Domains**에서 `cult.yourdomain.com` 추가 후 안내되는 CNAME 레코드 등록

## 💰 애드센스(AdSense) 코드 삽입 안내

이미 메인 워드프레스 도메인(`yourdomain.com`)이 애드센스 승인이 나 있다면, 하위 도메인(`cult.yourdomain.com`)은 **별도 승인 심사 없이 바로 광고가 게재**됩니다.

### 1. 하위 도메인 등록 (애드센스 콘솔)
1. 구글 애드센스 관리자 페이지 → **사이트(Sites)** 메뉴 이동
2. 이미 승인된 메인 도메인 클릭
3. **하위 도메인 추가(Add Subdomain)** 클릭 → `cult.yourdomain.com` 입력 후 저장

### 2. HTML 코드에 광고 태그 넣기 (`index.html`)
`index.html` 파일 내에서 `<!-- 여기에 실제 애드센스 코드 (ins 태그) 삽입 -->` 주석 부분을 찾아서 애드센스 단위 광고 코드로 교체하세요.

* **슬롯 1 (시작 화면 하단)**: 시작 전 클릭 유도
* **슬롯 2 (결과 화면 하단)**: 게임 종료 후 체류 시간 동안 노출 극대화

> **⚠️ 무효 트래픽 주의사항**:
> 본 프로젝트는 게임 선택지 버튼 주변에 애드센스를 두지 않고, 화면 최하단 안전 여백 구역에만 광고를 배치하여 구글 애드센스 정책 위반(오클릭 유도)을 원천 차단하도록 설계되어 있습니다.
